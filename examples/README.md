# Example: AGENTS.md as it ran in the experiments

`AGENTS.scaffold.md` is the instruction file in the form it had at the end of the third experiment, unchanged. Its section 4 describes the original scaffold repository (two disposable `hello` files and an early tooling stage), which is why it is kept here as an example and not offered as the template.

Use the root [`AGENTS.md`](../AGENTS.md) for your own projects. Compare the two to see what a filled-in section 4 looked like.

Sections 1 to 3 are the same in both except for one sentence in section 3. The template also opens with a comment explaining how to adapt it, and its section 4 is a fill-in form.
